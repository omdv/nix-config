NixOS emulator

Ephemeral and offline: files and configuration changes disappear on restart or when this page closes. No guest network, persistent disk, or host-directory access.

The browser downloads this release's assets; the guest itself has no internet access. Boot needs a browser with WebAssembly JSPI and enough memory for a 2 GiB guest. Initial loading and NixOS activation can take several minutes.

Idle — boot a fresh machine to begin.

Click the terminal to type. Control keys go to the guest; the terminal resizes with this window. Use Ctrl+Shift+C to copy selected text or Ctrl+Shift+V to paste.
